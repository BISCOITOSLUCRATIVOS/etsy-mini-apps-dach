# Etsy Mini Apps – DACH

Mini web apps autocontidas (HTML/CSS/JS puro, sem backend) para a loja Etsy orientada ao público alemão/suíço/austríaco, projeto Ordnungsheld.

Cada app vive na sua própria pasta e é 100% autocontida: um único `index.html`, sem dependências externas, dados guardados via `localStorage` no navegador do comprador.

## Apps

| App | Pasta | Conceito | Status |
|---|---|---|---|
| KlarLeben – Der All-in-One Lebensplaner | `klarleben/` | ADHS-Alltagsplaner | Phase 1–2 (arquitetura + núcleo funcional) |
| Minha Calculadora de Lucro – Biscoitos de Natal | `calculadora-lucro-biscoitos/` | Order Bump PT-BR: custo, preço e lucro para quem vende biscoitos de Natal | Completo e testado |

## Publicação

GitHub Pages serve este repositório; a `index.html` da raiz lista as apps publicadas. O link de cada app é usado apenas para pré-visualização/revisão interna — o produto final entregue na Etsy é o ficheiro `index.html` descarregado, não o link público.
